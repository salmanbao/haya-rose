# Aurelie Heirloom - Complete Stitch UI/UX Prompt System

## How to use these prompts

Use the existing `design.md` as the **immutable visual source of truth** for every screen below.

For every prompt:

* Preserve the existing Aurelie Heirloom color system.
* Preserve Playfair Display + Inter typography unless explicitly instructed to test an alternative.
* Preserve the minimalist editorial aesthetic.
* Preserve the 12-column desktop grid and 4-column mobile grid.
* Preserve the architectural whitespace.
* Preserve 2-4px corner radii.
* Do not introduce pill-shaped UI.
* Do not introduce gradients, glassmorphism, cartoon illustrations, childish motifs, excessive shadows, or generic SaaS UI.
* Do not invent a new color palette.
* Do not redesign the global navigation independently.
* Reuse existing components whenever possible.
* Maintain visual consistency with the approved landing page.
* Every page must feel like the same luxury European children's fashion atelier.
* Design both desktop and mobile responsive compositions.
* Prioritize real usability over decorative minimalism.
* Do not sacrifice usability merely to make the interface look luxurious.

The visual identity should communicate:

**quiet luxury, rarity, tenderness, craftsmanship, exclusivity, timelessness, modern heirloom.**

The customer should feel that they are purchasing something unusually special for an important moment in a child's life.

## 01. Newborn Collection / PLP

### Stitch Prompt

Design the **Newborn Collection / Product Listing Page** for Aurelie Heirloom.

This page is for newborn clothing from **0-3 months**.

The page must feel like a luxury fashion catalogue rather than a conventional ecommerce product grid.

### Page structure

1. Global Aurelie Heirloom navigation
2. Breadcrumb
3. Large editorial collection title
4. Collection description
5. Optional editorial collection image
6. Product count
7. Filter control
8. Sort control
9. Premium editorial product grid
10. Editorial story tile integrated into the grid
11. Pagination or progressive loading
12. Newsletter section
13. Footer

### Hero copy direction

Use restrained editorial messaging such as:

"THE NEWBORN EDIT"

"0 — 3 MONTHS"

"The first wardrobe, thoughtfully made for life's earliest days."

Do not use generic ecommerce copy such as "Shop our newborn clothes."

### Product grid

Do not create a dense Shopify-style grid.

Use generous whitespace, large product imagery, restrained product metadata, and occasional asymmetry.

Product cards should contain:

* Product image
* Brand / collection
* Product name
* Price
* Optional color indicator
* Wishlist icon
* Subtle hover image transition
* Optional quick view

Do not use large permanent Add to Cart buttons on every card.

### Filters

Design a refined filter drawer or overlay containing:

* Size
* Category
* Color
* Material
* Collection
* Price
* Availability

Filters must feel editorial and architectural rather than like a marketplace sidebar.

### Mobile

Use a two-column product grid with generous spacing.

Filter and sort should remain easily accessible.

Do not make mobile feel like a compressed desktop layout.

# FINAL MASTER CONSISTENCY PROMPT

After generating all pages, run this prompt against the entire Stitch project:

### Stitch Prompt

Audit the complete Aurelie Heirloom ecommerce experience against the existing `design.md`.

Do not redesign the brand.

Perform a **global visual and UX consistency audit** across every screen.

Verify:

## Brand consistency

* Colors are consistent
* Typography is consistent
* Playfair Display is used for editorial hierarchy
* Inter is used for functional UI
* Warm ivory remains the foundational surface
* Warm charcoal remains the primary text
* Muted taupe and champagne remain restrained accents

## Layout consistency

* 12-column desktop grid
* 4-column mobile grid
* 64px desktop page margins
* 20px mobile margins
* Consistent section spacing
* Consistent content widths
* Consistent image proportions

## Component consistency

Verify that the same components are visually identical wherever reused:

* Header
* Mega menu
* Footer
* Buttons
* Inputs
* Product cards
* Product gallery
* Price
* Wishlist
* Cart
* Accordions
* Breadcrumbs
* Filters
* Modals
* Toasts
* Empty states
* Error states

## Luxury consistency

Remove anything that makes the interface feel:

* childish
* mass-market
* generic
* overly commercial
* SaaS-like
* template-based
* visually noisy
* excessively rounded
* overly colorful
* overly animated

The experience should consistently communicate:

**quiet luxury**

**rarity**

**craftsmanship**

**tenderness**

**exclusivity**

**timelessness**

**modern heirloom**

## UX audit

Verify the complete customer journey:

Landing Page
→ Collection
→ Product
→ Add to Bag
→ Cart
→ Checkout
→ Payment
→ Confirmation
→ Tracking

Also verify:

Search
→ Results
→ Product

Navigation
→ Collection

Wishlist
→ Product
→ Bag

Gift Guide
→ Gift Product
→ Gift Configuration
→ Checkout

Account
→ Orders
→ Order Detail
→ Tracking

Identify any missing state, broken navigation path, inconsistent component, or UX dead end.

## Final principle

Aurelie Heirloom should feel like a luxury European children's fashion atelier that happens to have an exceptionally good ecommerce experience.

It must never feel like a generic ecommerce template that has been decorated to look luxurious.
