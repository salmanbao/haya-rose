## Directory Classification

Legend: **G** = generated by Medusa/Next.js starter · **C** = custom (this
project) · **E** = empty (placeholder) · **F** = intended for future extension

| Path | Purpose | G/C | Empty? | Future |
| --- | --- | --- | --- | --- |
| `apps/backend/` | Medusa commerce engine + Admin | G | No | Core app |
| `apps/backend/src/api/` | Custom API routes (file-based) | G | No (2 example routes) | F — store/admin custom endpoints |
| `apps/backend/src/workflows/` | Custom workflows | G | E (README only) | F — returns/refunds/notifications etc. |
| `apps/backend/src/modules/` | Custom modules | G | E | F — wishlist, reviews, bundles |
| `apps/backend/src/links/` | Module links | G | E | F — custom module↔core links |
| `apps/backend/src/subscribers/` | Event subscribers | G | E | F — order/payment events |
| `apps/backend/src/jobs/` | Scheduled jobs | G | E | F — abandoned cart, low stock |
| `apps/backend/src/admin/` | Admin dashboard extensions | G | E (i18n stub) | F — admin UI for custom features |
| `apps/backend/src/migration-scripts/` | Custom data/seed scripts | G | No (seed) | F — catalog seeding, data migrations |
| `apps/backend/integration-tests/` | Jest integration harness | G | E (setup only) | F — API/module tests |
| `apps/storefront/` | Customer-facing storefront | G | No | Core app |
| `apps/storefront/src/app/` | App Router pages | G | No | F — new pages per feature |
| `apps/storefront/src/lib/` | SDK/data-fetch/util layer | G | No | F — feature data modules |
| `apps/storefront/src/modules/` | UI components/modules | G | No | F — feature UI |
| `apps/storefront/public/` | Static assets | G | — | media/static |
| `docs/` | Project documentation | C | No | F — ADRs, specs, plans |
| `.agents/` | Agent tooling | C (pre-existing) | No | — |

## Notes

- The DTC starter's own `AGENTS.md` was not copied in, preserving the
  pre-existing authoritative root `AGENTS.md` (project contract).
- All `.env*` files and generated output (`.medusa/`, `.next/`, `node_modules/`,
  `.turbo/`) are gitignored.
- No custom code exists beyond the initialization lint fixes in two storefront
  files (`src/lib/data/cart.ts`, `src/modules/layout/components/language-select/index.tsx`)
  and the added `.env.example` files — both documented in the gap analysis.
